## About Me

I am a CNRS researcher at the CRIStAL laboratory in Lille, France, where I am a member of the Bonsai bioinformatics team.
My research focuses on developing efficient computational methods to analyze the massive amounts of data generated by DNA sequencing technologies, bridging the gap between theoretical computer science and practical biological data analysis. 
My goal is to create scalable, efficient, and accessible tools that enable new discoveries in genomics, transcriptomics, and metagenomics.

## 🛠️ Software Tools
All  my projects are open-source. Here are some of the key software packages developed.


* **[BCOOL](URL)**: A conservative short-read error corrector using a meticulously cleaned de Bruijn graph.
* **[BGREAT](URL)**: A tool for mapping sequencing reads directly onto a de Bruijn graph.
* **[BLIGHT](URL)**: A static and exact k-mer dictionary using minimizer-partitioned MPHFs for high performance.
* **[BRISK](URL)**: An exact and dynamic dictionary for large k-mer sets, offering significant memory savings.
* **[BRRR](URL)**: A linear-time long-read correction tool based on the k-mer spectrum.
* **[BWISE](URL)**: A short-read assembler designed to handle highly heterozygous and polyploid genomes.
* **[CBL](URL)**: A dynamic k-mer set structure supporting fast set operations like union and intersection.
* **[CONSENT](URL)**: A scalable tool for long-read self-correction and assembly polishing.
* **[ELECTOR](URL)**: An evaluation tool for long-read error correction methods, providing detailed metrics.
* **[K2R](URL)**: An index that efficiently maps k-mers to the specific reads they came from (Tinted de Bruijn Graph).
* **[KFC](URL)**: A fast k-mer counter based on the novel and space-efficient hyper-k-mer data structure.
* **[Kloe](URL)**: A tool for compressing and retrieving k-mer sets from a specific dataset within a large collection.
* **[LPHASH](URL)**: A locality-preserving minimal perfect hash function library that is highly space-efficient for k-mer sets.
* **[MSALIMIT](URL)**: A benchmark framework for the systematic evaluation of Multiple Sequence Alignment techniques.
* **[NIQKI](URL)**: A tool for ultra-fast, large-scale comparison of genomic sketches using an inverted index.
* **[ONIKA](URL)**: An improved version of NIQKI with tunable fingerprints and a balanced inverted index.
* **[OREO](URL)**: A tool that reorders long reads based on a draft assembly to improve their compressibility.
* **[OREOMINI](URL)**: A lightweight version of OREO using one-bit MinHash sketches for fast read partitioning.
* **[PAC](URL)**: A scalable tool for indexing and querying k-mer presence in massive collections of sequencing data.
* **[REINDEER2](URL)**: An index for storing and querying k-mer abundances across large dataset collections.
* **[STRONG](URL)**: A pipeline for resolving microbial strains from metagenomic assembly graphs.
* **[SUPERSAMPLER](URL)**: A sketching tool that uses a fractional hitting set of super-k-mers for efficient comparison.
